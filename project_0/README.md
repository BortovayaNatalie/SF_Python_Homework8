### <a id="title1">Описание проекта</a>
Угадать загаданное компьютером число за минимальное число попыток (не более 20)

:arrow_up:[к оглавлению](#title0)
### <a id="title2">Какой кейс решаем?</a>
Нужно написать программу, которая угадывает числа за минимальное число попыток

**Условия соревнования**
- Компьютер загадывает целое число от 0 до 100, и нам его нужно угадать. Под "угадать", подразумевается "написать программу, которая угадывает число".
- Алгоритм учитывает информацию о том, больше ли случайное число или меньше нужного нам.
- Необходимо добиться того, чтобы программа угадывала число меньше, чем за 20 попыток

**Метрика качества**
Результаты оцениваются по среднему количеству попыток при 1 000 повторений.

**Что практикуем**
- Учимся писать хороший код на Python.
-  Учимся раотать с IDE.
- Учимся работать с GitHub.

### <a id="title4">Этапы работы над проектом</a>
- Изучаем два простейших алгоритма решения задачи, данных в шаблоне задания. Это алгоритм "Случайное угадывание" и алгоритм "Угадывание с коррекцией". Результаты работы обоих алгоритмов не укладываются в требования соревнования. В шаблоне даны функция для оценки работы алгоритмов и методика сравнения результатов
- Используем для решения задачи алгоритм бинарного поиска: на каждом шаге находим середину текущего диапазон, запрашиваем - угадали ли число. Сужаем диапазон в зависимости от ответа программы, повторяем с серединой нового диапазона.
- Проверяем алгоритм на эффективность по данной методике

### <a id="title5">Результаты</a>
Программа, использующая алгоритм бинарного поиска угадывает число в среднем за 5 попыток, что значительно лучше заданного ограничения в 20 попыток.
